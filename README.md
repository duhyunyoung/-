# 🥬 대파 — 대신 파라 드립니다

동네 기반 중고거래에 **"우리 동네에 없으면 인접 동네·전국 안심거래로 바로 확장"** 과
**"원하는 판매자만 고르는 무보관·개인정보 비공개 판매대행"**, **에스크로·노쇼 예약금·정찰제**를 얹은 모바일 웹앱 MVP입니다.

- 기본 판매 방식은 **판매자–구매자 직접 거래**이고, 대행은 원하는 판매자만 선택하는 모드입니다.
- 대행은 **무보관 · 개인정보 비공개 온라인 대행**: 물건은 판매자 집에 그대로, 대파가 비공개로 등록·응대하고 **판매 확정 시에만 택배 수거**해 발송·정산합니다(창고 보관 0원, 번호·주소·계좌 노출 0%).

**▶ 라이브 데모: https://duhyunyoung.github.io/-/**

- 실행 파일: **`index.html`** (단일 파일, 외부 요청 0건). 이 저장소 루트의 파일이 그대로 GitHub Pages로 서빙됩니다.
- 로컬에서 열려면 `index.html`을 더블클릭하거나, 저장소 루트에서 로컬 서버로 열어도 됩니다.
  ```bash
  python3 -m http.server 8080
  # 브라우저에서 http://localhost:8080
  ```
- 모든 데이터는 `localStorage`(`daepa.state.v1`)에만 저장됩니다. 서버·외부 전송·배포·푸시 없음.

## 1. 이 앱이 당근과 다른 지점 (첫 화면에서 바로 보이는 것)

| 당근의 아픈 지점 | 대파의 해결 |
|---|---|
| 내 동네에 매물이 없으면 끝 | 홈 상단 **내 동네 → 인접 동네 → 전국 확장** 3단 스코프. 각 단계에 매물 수가 실시간으로 표시되고, 부족하면 `인접 +12 →` 로 바로 넓힘. 하단에 **"인접 동네에서 더 찾아봤어요"** 섹션이 항상 대기 |
| 사진 올리고 응대하고 발송하는 게 다 내 일 | **대파 판매 대행(원하는 판매자만 선택)**: 정보 등록 → 비공개 대행 판매 → 판매 확정 시 택배 수거 → 안심 정산. 수수료 10%(최소 1,000원), 안 팔리면 0원. **창고 보관 없음 · 판매자 번호·주소·계좌 노출 0%**. 폼에서 **정산 예정 금액**이 실시간 계산됨 |
| 선입금 사기 · 노쇼 | **안심결제(에스크로)**: 결제금을 대파가 보관, 구매확정 후 정산. **노쇼 방지 예약금**: 상품가 10%를 걸고 직거래 약속, 노쇼 시 상대에게 지급 |
| 네고 지옥 | **정찰제 토글**: 켜면 상세에서 "네고 없이 이 가격에 거래돼요"로 잠금 표시 |

## 2. 구현된 화면과 동작

### 홈 (`data-view="home"`)
- 동네 셀렉터(역삼동·서초동·삼성동·논현동·대치동·신사동, 동별 매물 수 표시) → 바꾸면 인접 동네 집합이 함께 재계산
- 3단 스코프 세그먼트(내 동네 8 / 인접 20 / 전국 25) + 단계별 안내 문구 + 다음 단계 확장 칩
- 신뢰 배지 스트립: 에스크로 결제 · 노쇼 예약금 · 정찰제 · 개인정보 비공개 · 판매대행(선택)
- 정책 안내 배너: **"판매는 직접 거래가 기본, 대행은 원하는 분만"** + 무보관·개인정보 비공개(노출 0%)·판매 확정 시에만 택배 수거 → 누르면 대행 모드 등록 폼으로 이동
- 검색(제목·설명·카테고리·동네), 카테고리 8종, 정렬 3종(추천/최신/낮은 가격) 순환
- 2열 카드: 카드별 배지(대파 판매대행/정찰제/예약금/동네 직거래/타지역 안심배송), 찜 토글, 가격·동네·시간
- **빈 상태**: "역삼동엔 '가구' 매물이 없어요 → 인접 12개·전국 5개" + 원터치 확장 버튼. 검색 무결과일 때는 '검색어 지우기 / 전국 보기'로 분기
- **확장 티저**: 현재 범위 밖 매물을 가로 스크롤로 먼저 보여주고 "전체 보기"

### 상품 상세 (카드 탭)
- 히어로 3장(전체/클로즈업/반대 각도) 썸네일 전환, 배지 5종, 제목·가격·정찰제 잠금 안내
- 판매자/대파 대행자 카드(신뢰도·거래수·응답률·비공개 대행 태그) + 문의
- 대행 상품에는 **"판매자 개인정보 비공개 · 대파 안심 대행"** 카드(번호·주소·계좌 노출 0%, 창고 보관 없음, 판매 확정 시에만 택배 수거·구매확정 후 정산)와 `정보 비공개` 태그, 거래 정보의 `대행 방식: 무보관 · 정보 비공개 대행` 행
- 거래 정보(직거래 장소, 안심배송 택배사·도착 예정, 상품 상태)
- 안심거래 3단계 안내(결제 보관 → 배송·직거래 → 구매확정 정산)
- 하단 고정 CTA: `안심결제 구매하기` / `예약금` / `채팅`
  - **에스크로 결제 시트**: 상품가·배송비(30만원 이상 무료)·이용료 2%·총액 → 결제 완료 화면(주문번호·도착 예정·보관 금액)
  - **예약금 시트**: 약속 시간 선택, 예약금 10%·현장 잔금 계산, 노쇼/판매자 노쇼 2배 보상 안내 → 예약 확정
  - **채팅 시트**: 대화 기록 저장, 전송 시 자동 응답(데모), 결제 전 대화도 기록된다는 안내

### 판매 등록 (하단 중앙 버튼)
- **직접 등록(기본) / 대파에 맡기기(선택)** 모드 전환 — 폼을 열면 항상 **직접 등록**이 선택돼 있고, 대행은 `선택` 배지가 붙은 옆 버튼
- 직접 등록 모드: "기본은 판매자–구매자 직접 거래" 안내, 대파는 안심결제로 결제금만 보관
- 대행 모드(원하는 판매자만): "대파가 대신 팔아드립니다" 카드 + **정보 등록 → 비공개 대행 판매 → 판매 확정 시 수거 → 안심 정산** 4단계, `개인정보 비공개(번호·주소·계좌 노출 0%)` / `창고 보관 없이 판매 확정 시에만 택배 수거` 하이라이트, `판매 확정 시 택배 수거` 토글, **초기 오픈 안내: 명품·고가 진품 감정이 필요한 품목은 대행 대상에서 제외**
- 사진 3장(예시 일러스트 선택 또는 **내 사진 업로드** — FileReader로 미리보기), 상품명, 카테고리, 희망가(콤마 자동 포맷·빠른 가격), 상태, 거래 방식, 정찰제 토글, 설명
- **실시간 수수료 계산**: 판매가 → 수수료 10% → **정산 예정 금액**
- 검증(상품명 2자·가격 1,000원 이상) 후 등록 → 직접 등록은 상세로 이동·피드 노출, 대행은 내 거래에 `정보 등록` 상태로 생성

### 내 거래
- 프로필(동네·신뢰도·거래 횟수) + 요약(정산 예정 금액 / 진행 중 거래 / 찜)
- 탭 4개: **대행 판매 / 안심 구매 / 예약 직거래 / 찜한 상품**
- 각 카드에 4단계 스테퍼: 대행(**정보등록 → 판매중(비공개) → 택배수거 → 정산완료**), 구매(결제완료→배송중→구매확정), 예약(예약 확정→직거래 완료)
- 대행 카드 동작: 판매중 상품에 **`택배 수거 요청`** 버튼 → `수거 요청` 상태 + 운송장·방문 예정 배너 + 스테퍼 `택배수거`로 전환, 이후 `운송장 보기`
- 동작: **구매확정**(정산 전환), 예약 취소, 배송 조회(운송장), 대파에 문의
- 데모 데이터 초기화(확인 시트 → 기본 상태 복원)

## 3. 구조

```
이 저장소 (GitHub Pages: gh-pages 브랜치 / 루트 · main도 같은 내용)
├─ index.html               # 앱 전체 — 단일 파일 (약 134KB, 외부 요청 0)

개발 워크스페이스 (daepa-app/)
├─ src/
│  ├─ index.template.html   # 셸(메타·파비콘·마운트 지점)
│  ├─ styles.css            # 디자인 시스템 (그린 팔레트, 430px 프레임, 시트/토스트)
│  ├─ data.js               # 아이콘·SVG 일러스트 28종·팔레트·동네·시드 매물 25개
│  └─ app.js                # 상태(localStorage)·라우팅·렌더·이벤트
├─ build.py                 # 3파일 → dist/index.html 단일 파일 인라인 빌드
├─ dist/index.html          # 결과물 (134.5KB, 외부 요청 0)
├─ verify.py                # Playwright 자동 검증 + 스크린샷 재생성
└─ screenshots/             # 검증 스크린샷 (저장소에는 미포함)
```

- Node/npm이 없는 환경이라 **의존성 없는 정적 빌드**로 만들었습니다. `python3 build.py` 한 번이면 재빌드됩니다.
- 폰트·아이콘·이미지 모두 시스템 폰트/인라인 SVG라 **깨진 이미지·외부 CDN 요청이 0건**입니다.
- 데스크톱에서는 430px 모바일 프레임으로 중앙 정렬, 모바일에서는 전체 폭. 360/375/390/430px 모두 가로 스크롤 없음.

## 5. 범위와 한계 (데모)

- 결제·배송·정산은 **화면과 상태 전이만 구현한 시뮬레이션**입니다(실 PG 연동 없음).
- 회원가입/로그인 없음 — 사용자는 `DUrake · 역삼동`으로 고정, 데이터는 기기 로컬에만 존재.
- 매물 이미지는 사진 대신 **인라인 SVG 일러스트**를 사용했습니다(깨진 이미지 0 보장). 직접 등록 시에는 실제 사진 업로드·미리보기가 동작합니다.
