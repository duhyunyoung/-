# 엘리의 간식 마을

사탕 나무, 젤리 연못, 과자집이 있는 달콤한 마을에서 친구들의 부탁을 들어주는 2D 웹 놀이입니다.

- 놀이 주소: https://duhyunyoung.github.io/-/sweet-town/
- 폰(아이폰 사파리)에서 주소를 열면 바로 시작합니다. 설치할 것은 없습니다.

## 노는 방법

- 화면을 **톡** 누르면 엘리가 그곳으로 걸어갑니다. 왼쪽 아래 동그란 스틱을 끌어도 움직일 수 있어요.
- 동물 친구(솜솜·코코·젤리·삐약)와 꼬마 친구(루나·하루·보라) 가까이 가면 오른쪽 아래 큰 버튼이 **말 걸기**로 바뀝니다.
- 롤리팝 나무, 솜사탕 덤불, 마시멜로 덤불, 초콜릿 나무 가까이에서 **줍기**로 간식을 모읍니다.
- 젤리 연못 가까이에서 **낚시**를 누르고, 초록색 칸에 표시가 올 때 **톡!** 하면 구미베어·별젤리를 낚을 수 있어요.
- 부탁을 해결하면 **별 코인**을 받고, 상점에서 가구를 살 수 있어요.

## 과자집 안 (2차 업그레이드)

- 과자집 문 앞에서 **집에 들어가기**를 누르면 과자집 안으로 들어갑니다. 안에서 **마을로 나가기**를 누르면 다시 마을로 나와요.
- 집 안에는 딸기 케이크 테이블, 쿠키 오븐, 솜사탕 침대, 초코 벽난로, 젤리 창문이 있어요.
- 쿠키 오븐 앞에서 **쿠키 굽기** → 조금 기다렸다가 **쿠키 꺼내기**를 누르면 따뜻한 쿠키를 얻습니다. 케이크 테이블에서 **케이크 먹기**도 할 수 있어요.
- 꼬마 친구 **모모**가 집 안에 살고 있어요.
- 집 안에서도 **꾸미기**가 됩니다. 집 안 가구는 `placedIn`, 마을 가구는 `placed`에 따로 저장됩니다.
- 상점에는 마을 가구, 과자집 안 가구, 어디든 놓는 가구가 함께 있고 카드에 표시됩니다.
  - 새 가구 6종: 곰젤리 램프, 딸기 케이크 분수, 하트 마카롱 의자, 별빛 솜사탕 침대, 쿠키 오븐 장식, 무지개 사탕 아치.
- 기본 부탁 7개 뒤에 꼬마 친구들의 새 부탁 5개가 이어지고, 그 뒤로는 반복 부탁이 계속됩니다.

## 저장

마을 배치, 과자집 안 배치, 별 코인, 모은 간식, 부탁 진행, 있던 자리는 폰 브라우저(localStorage)에 저절로 저장됩니다.
1차 버전의 저장 데이터가 남아 있어도 그대로 이어서 놀 수 있고, 새 항목(집 안 배치·따뜻한 쿠키 등)은 안전하게 채워집니다.
처음부터 다시 시작하려면 오른쪽 위 **?** → **마을 처음부터 다시 시작하기**를 누르세요. (확인창이 뜹니다.)

## 만든 방식

- HTML5 Canvas와 CSS로만 그렸습니다. 외부 이미지·폰트·CDN을 쓰지 않아 인터넷이 느려도 바로 열립니다.
- 소리와 배경 음악은 WebAudio로 직접 합성합니다.
- 모바일 사파리를 위해 `100dvh`와 `env(safe-area-inset-*)`를 적용했고, 파일 주소에 `?v=2`를 붙여 캐시를 피합니다.
