# 엘리의 간식 마을

사탕 나무, 젤리 연못, 과자집이 있는 달콤한 마을에서 동물 친구들의 부탁을 들어주는 2D 웹 놀이입니다.

- 놀이 주소: https://duhyunyoung.github.io/-/sweet-town/
- 폰(아이폰 사파리)에서 주소를 열면 바로 시작합니다. 설치할 것은 없습니다.

## 노는 방법

- 화면을 **톡** 누르면 엘리가 그곳으로 걸어갑니다. 왼쪽 아래 동그란 스틱을 끌어도 움직일 수 있어요.
- 동물 친구(솜솜·코코·젤리·삐약) 가까이 가면 오른쪽 아래 큰 버튼이 **말 걸기**로 바뀝니다.
- 롤리팝 나무, 솜사탕 덤불, 마시멜로 덤불, 초콜릿 나무 가까이에서 **줍기**로 간식을 모읍니다.
- 젤리 연못 가까이에서 **낚시**를 누르고, 초록색 칸에 표시가 올 때 **톡!** 하면 구미베어·별젤리를 낚을 수 있어요.
- 부탁을 해결하면 **별 코인**을 받고, 상점에서 롤리팝 가로등·마카롱 테이블·초코 분수·젤리 화분·솜사탕 소파·과자 울타리를 살 수 있어요.
- **꾸미기**를 누르면 점선 칸을 톡 눌러 가구를 놓고, 놓인 가구를 다시 눌러 가져올 수 있어요.
- 오른쪽 위 스피커 버튼으로 소리를 끄고 켤 수 있어요.

## 저장

마을 배치, 별 코인, 모은 간식, 부탁 진행은 폰 브라우저(localStorage)에 저절로 저장됩니다.
처음부터 다시 시작하려면 오른쪽 위 **?** → **마을 처음부터 다시 시작하기**를 누르세요. (확인창이 뜹니다.)

## 만든 방식

- HTML5 Canvas와 CSS로만 그렸습니다. 외부 이미지·폰트·CDN을 쓰지 않아 인터넷이 느려도 바로 열립니다.
- 소리와 배경 음악은 WebAudio로 직접 합성합니다.
- 모바일 사파리를 위해 `100dvh`와 `env(safe-area-inset-*)`를 적용했습니다.
