# 🐰 토끼잡기 — 웹 카드게임

코리아보드게임즈 〈토끼잡기〉의 **원본 규칙을 그대로** 구현한 모바일 웹 카드게임입니다.
실물 제품 이미지는 쓰지 않고, 이모지·CSS로 카드와 카드 뒷면을 자체 디자인했습니다.

- 플레이: https://duhyunyoung.github.io/-/rabbit/
- 인원: 2~6명 · 약 10분

## 규칙 (원본 그대로)

- 카드 52장 = 채소 12종 × 4장(48장) + 토끼 도둑 카드 4장
- 시작: **토끼 카드 1장을 빼고** 51장을 골고루 나눠 줌 (설정에서 공식 변형 '무작위 1장 빼기' 선택 가능, 기본값은 원본 규칙)
- 나눠 받자마자 손에 같은 카드 2장이 있으면 즉시 버림 (0장이 된 사람은 즉시 탈출)
- 자기 차례에 시계 방향 다음 사람의 손에서 뒷면 카드 1장을 뽑음
- 뽑은 카드가 내 손의 카드와 같으면 2장을 함께 버림, 다르면 손에 남음
- 손의 카드가 0장이 되면 즉시 탈출(승리 확정)
- 마지막까지 카드를 들고 남은 1명이 패배 — 나머지 전원 승리. 마지막에 빼둔 카드도 공개

## 모드

1. **AI 대전** — 나 1명 + AI 1~5명. AI는 0.7~1초 간격으로 차례를 진행하고, 누가 누구에게서 뽑았는지·짝을 버렸는지 배너로 안내
2. **한 기기에서 (패스 앤 플레이)** — 2~6명. 차례가 바뀔 때마다 가림막으로 남의 패를 가림
