# 🪜 사다리 타기 (Coding Gamer) — 1차 버전

`https://duhyunyoung.github.io/-/ladder/` 에서 바로 실행되는 모바일 웹게임입니다.
빌드 도구·외부 라이브러리 없이 `index.html` 한 파일로 동작합니다(아이폰 사파리 세로 화면 기준).

## 플레이 흐름

1. 인원(2~6명)과 출발 이름 / 도착 결과를 입력하고 사다리를 만듭니다. 프리셋으로 바로 시작할 수 있습니다.
2. 위쪽 이름을 눌러 차례를 고르고 `출발!`을 누르면, 그 참가자가 사다리를 타고 내려갑니다.
3. 사다리 중간 상점 3곳을 지날 때마다 상점 창이 열리고, 상점마다 주사위를 1번 굴립니다.
4. 모은 코인으로 아이템을 사고 `계속 내려가기`로 다시 내려갑니다.
5. 도착하면 결과·획득 코인·산 아이템이 나오고, 모든 참가자가 끝나면 최종 결과 화면이 나옵니다.

## 규칙 (1차 확정)

| 주사위 | 보상 |
|---|---|
| 5 | 코인 1개 |
| 6 | 코인 5개 |
| 1~4 | 0개 |

- 주사위는 **상점마다 1번**(참가자별). 굴리지 않고 그냥 내려갈 수도 있습니다.
- 코인과 아이템은 **참가자별로 따로** 쌓입니다.
- 상점 아이템(효과 미정 테스트 슬롯): `임시 아이템 A` 1코인, `임시 아이템 B` 3코인, `임시 아이템 C` 5코인.

## 다음에 손볼 곳

`index.html` 안의 상수만 바꾸면 됩니다.

- `ITEMS` — 아이템 이름·가격·아이콘과 `note`(효과 설명). 효과가 정해지면 여기서 문구를 바꾸고 실제 효과 코드를 연결합니다.
- `SHOP_LEVELS` — 상점이 놓이는 가로줄 위치(현재 12줄 중 4·7·10번째).
- `LEVELS` — 사다리 가로줄 개수.
- 주사위 보상 비율 — `rollDice()` 안의 `st.gain` 계산.

## 메모

- 5·6이 나올 확률이 1/3이라, 상점 3곳에서 한 번씩만 굴리면 3번 모두 0코인일 확률이 약 58%입니다(밸런스 조정 여지).
- 이 페이지는 공개 저장소에 올라가 있어 주소와 소스가 누구나 볼 수 있습니다.
